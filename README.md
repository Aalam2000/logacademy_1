# Log Academy — учебная платформа

Веб-платформа учебного центра [Log Academy](https://logacademy.az) для ведения групп, уроков, посещаемости, оценок и домашних заданий. Интерфейс на русском, азербайджанском и английском.

## Статус

Платформа в рабочей эксплуатации: используется в учебном процессе академии — педагоги ведут на ней группы и уроки, студенты получают материалы и сдают домашние задания. Развивается.

## Роли

| Роль | Возможности |
|---|---|
| **Администратор** | курсы, педагоги, группы; база знаний и шаблоны курсов; статистика по педагогам; посещения платформы |
| **Педагог** | свои группы: расписание, уроки, материалы, посещаемость, оценки, домашние задания, квизы, видеоконференция |
| **Студент** | свои уроки (таблица и календарь), материалы, домашние задания, диалог с педагогом, успеваемость |

## Возможности

- **Группы и расписание** — генерация серии уроков по дням недели, времени и длительности; перенос урока на «выходной» со сдвигом последующих; календарь «Месяц / Неделя / День» с реальной длительностью уроков.
- **Уроки** — материалы из общей базы знаний (файлы, ссылки, квизы); урок открывается студентам по решению педагога; оценки и присутствие фиксируются в полночь дня урока (по Баку).
- **Посещаемость и оценки** — пришёл / онлайн / уважительная причина / опоздание; три оценки по шкале 0–100: за урок, за домашнее задание, экзаменационная; звёзды. Пропуск засчитывается автоматически по единому правилу для всех отчётов.
- **Домашние задания** — общие и персональные задания со сроком сдачи, ответы студентов, проверка, возврат на доработку, диалог педагога со студентом.
- **База знаний** — файлы с контролем дублей; просмотр docx / xlsx / pptx в браузере через PDF; шаблоны материалов по курсам.
- **Живые квизы** — игра в классе в реальном времени, вход студентов по QR-коду или коду игры.
- **Видеоконференция** — у каждой группы постоянная ссылка (Google Meet или другой сервис); кнопка входа у педагога и у студента.
- **Отчёты** — таблица студентов со средними оценками, пропусками и опозданиями; PDF-карточка студента; посещаемость по педагогам.
- **Посещения платформы** — кто сейчас в системе; отчёт по пользователям: дни, первый вход, последняя активность, время в системе. Учитывается только время (без IP, браузера и открытых страниц), хранится год.
- **Автоперевод интерфейса** — тексты извлекаются из кода и переводятся автоматически.
- **Защита данных при удалении** — нельзя удалить объект, который где-то используется; система показывает, где именно.

## Стек

| Часть | Технологии |
|---|---|
| Backend | Python 3.12, FastAPI, Pydantic 2, SQLAlchemy 2 (async), Alembic |
| Frontend | React 18, Vite, React Router, react-big-calendar |
| Данные | PostgreSQL — база данных; MinIO — хранилище файлов |
| Документы | LibreOffice — просмотр офисных файлов; xhtml2pdf — PDF-отчёты |
| Перевод | autoi18n + OpenAI |
| Инфраструктура | Docker, Nginx |

## Устройство

```
backend/            API и бизнес-логика
  app/routers/        разделы API: группы, уроки, ДЗ, материалы, квизы, студенты…
  app/models.py       модель данных
  app/attendance.py   правило посещаемости
  app/lesson_lock.py  правило фиксации урока
  app/usages.py       проверка использования перед удалением
  app/presence.py     правила учёта присутствия в системе
  app/storage.py      работа с файловым хранилищем
  alembic/            миграции базы данных
  templates/          HTML-шаблоны квизов, карточки студента, справки
frontend/           веб-интерфейс
  src/pages/          страницы
  src/components/     общие компоненты
  src/api/            обращения к API
  src/styles/         дизайн-токены и стили
deploy/             конфигурация Nginx и системных сервисов
scripts/            служебные скрипты
```
